# Element Drift — Max/MSP 版 (Phase 3)

ZIG SIM PRO のセンサーストリームから運動共感エレメント10要素の活性度を抽出し、
スポットライトの当たった要素が万能シンセを駆動する。

## ファイル

- `ElementDrift.maxpat` — メインパッチ (受信 → js → 制御ストリーム分配 → ボイス合流 → gain → リバーブ)
- `elements.js` — 制御ロジック全部 (OSCパース・特徴抽出・正規化・ドリフト・重み・イベント・セルフテスト)。**音は決めない**
- `elem.<名前>~.maxpat` ×10 — 要素ボイス。**音の設計はここで行う (あなたの領分)**
- `mapping.json` — ドリフトの到達可能性行列 reach のみ
- `../tools/harness.js` — Max なしで全検証を回す (`node tools/harness.js max/elements.js`)

## アーキテクチャ: 1要素 = 1ボイスパッチ

js は音を決めず、制御ストリームだけを送る。各要素の音は `elem.<名前>~.maxpat` を
開いてパッチングで設計する (中身は完全に自由。既定は聴き分け用の仮ドローン)。

ボイスの契約 (これだけ守れば何をしてもよい):
- `[r ed-acts]` — 10要素の活性度リスト (0..1、20Hz)。unpack して自分の要素の値を使う
- `[r ed-weights]` — スポットライト重み (温度リーク込み・なめらか)。自分の重みを音量等に使う
- `[r ed-events]` — `arc-stop <鋭さ>` (円弧の完結) / `onset <強さ>` (動き出し)。打撃系のトリガに
- `[r ed-motion]` — `<lin> <rot> <speed>` (0..1、20Hz)。動きの生の激しさ (獲物のゲートを経由しない)。
  音色のミクロ変調 (レゾナンス周波数・グライドの揺れ・グレイン速度など) に使う
- `distance` (ed 制御ストリーム、メインパッチが直接消費) — 放置すると 0→1 に遠ざかる (こもる・
  ドライ減・残響増)。動くと 1-2 秒で戻る。ボイス側は触らなくてよい
- 音は outlet (signal) へ。合流後に **master gain ∝ Σw·a** が一括でかかる —
  表出しないと鳴らない (作品の心臓部) はボイスの外で保証される

設計原理 (運動共感の観点):
- その要素の運動プロファイルをエンベロープ類型で写す —
  impulsive (関節・加速: 打撃→減衰) / sustained (張力・重力・静止: 押す・支える) /
  iterative (振動・リズム: 反復)
- 動きたくなるリズムは中程度のシンコペーション・1〜3Hz 帯 (グルーヴ研究の逆U字)
- スポットライト固定 (number box 0-9) で1要素ずつ音作り → `-1` でドリフトに戻して通しで聴く

## 追跡方策 (自動モード): 逃げる獲物を音で追う

自動モードでは、獲物 (prey) = 10要素単体上の連続な点が、ダンサーの現在の
活性プロファイルから**連続的に逃げる**。音の混合重み (ed-weights) は獲物の
位置なので、音は場面転換せず滑らかに移ろう。**何が鳴るか = prey (音色配合)、
どう鳴るか = motion (動きの生の激しさによるミクロ変調)** に分離している。

- 獲物の速度 = 逃走 (近づかれるほど速い) + 低慣れ要素への引力 (`PREY_SPEED/FLEE_W/GOAL_W`)
- **gain = 近さ (closeness) の連続勾配** — 温かい/冷たいが常に聞こえる。
  下限 `GAIN_FLOOR=0.08` で完全無音にはしない (勾配が消えると追えない)
- 獲物の argmax が変わると `prey <name> closeness <値>` が print される
- `logging 1` で 200ms 毎に act/prey/closeness を print (将来の ML 学習データ収集用)
- 手動 (`spotlight 0-9`) は従来通り one-hot + gain=活性 (音作り用)

## チューニングと確認

- 音: `elem.<名前>~.maxpat` を編集して保存 (メインパッチを開き直すと反映)
- ドリフトの近さ: `mapping.json` の reach を編集 → パッチの `import mapping.json` → `loadmap`。
  dict が無い/壊れている場合は elements.js 内の既定値にフォールバックする
- 音を出す: パッチ左下の ezdac~ (スピーカーアイコン) をクリック
- js のコード変更後は `node tools/harness.js max/elements.js` で ALL PASS を確認

## ZIG SIM PRO 側の設定

- **SENSOR**: Acceleration / Gravity / Gyro を ON (Quaternion は Phase 2 で使用予定なので ON でも可)
- **SETTINGS**:
  - DATA DESTINATION: OTHER APP
  - PROTOCOL: UDP
  - IP ADDRESS: Mac の IP (同一 Wi-Fi)
  - PORT NUMBER: **9600**
  - MESSAGE FORMAT: **OSC**
  - MESSAGE RATE (PER SEC): 最大値 (60)

## 使い方

1. `ElementDrift.maxpat` を開く (elements.js は同フォルダにあるので自動で読まれる)
2. **電話なしで動作確認**: `selftest 1` をクリック。5秒ごとに
   静止 → 傾き → 振動 → リズム → 回転 → 加減速 のパターンを合成生成し、
   対応するバーが順に立てば正常。Max ウィンドウに segment 名が print される。
   `selftest 0` で停止。
3. 実機: ZIG SIM PRO を上記設定で送信開始。「受信Hz」に実効レートが表示される。
   accel が重力込みか否かは受信開始後 約100サンプルで自動判定される
   (Max ウィンドウに `accelmode ...` と表示)。
4. `reset` で走行正規化の min/max をリセット。

## v2 (element_drift_v2.html) からの変更点

- 重力分離: 窓平均ハックを廃止し、CoreMotion 由来の gravity / userAcceleration を直接使用
- 傾き: スマホの傾き角そのもの (動きによる抑制項を廃止)
- 回転: 自転と公転の max。
  自転 (ジャイロ): 支配回転軸の安定性 × 方向の持続 × (0.7 + 0.3·遠心力の証拠)。
  遠心力はボーナス扱い — 半径ゼロ付近の平面スピンでも立つ。
  公転 (加速度): 姿勢を保ったまま腕で円周上を回る動き。向心加速度ベクトルが
  一定の向きに回り続けること (a × ȧ の一貫性) から公転角速度を推定。
  往復 (振り子的な弧) は外積の向きが反転して打ち消される
- 関節: 円弧への確信の漸増モデル。円弧が続くほど「これは円弧的な動きだ」という
  確信度が徐々に上がり (掃引角 ARC_FULL=2.5rad で満了、上限 0.6)、停止した瞬間に
  円弧の完結として穏やかなボーナス (最大 +0.4、停止の鋭さに比例)。突然爆発しない。
  止まらずに回り続けると回転とみなし、1 秒を超えたあたりから確信が薄れていく —
  スピンの序盤に関節が少し立ってから回転に譲る挙動は「最初は円弧か回転か
  分からない」という知覚の曖昧さをそのまま写している
- 重力: 加速度の鉛直成分の大きさ × 動きの鉛直性。重力方向への移動 (落下・沈み) と
  重力に抗う移動 (上昇・持ち上げ) の両方を等しく計る。自由落下は鉛直成分
  9.8 m/s² として自然に最大級になる
- 振動/張力: 帯域分離に変更。加速度 (符号つき・軸別) の 1.5 秒窓を Goertzel で周波数分解し、
  各周波数のエネルギーを SPLIT_HZ (4.5Hz) 中心のゆるやかなシグモイドで
  張力側 (低域: しなやかな揺れ) と振動側 (高域: 速い震え) にクロスフェード按分。
  中間の周波数は両方にゆるやかに寄与する。なだらかさは SPLIT_W で調整
- 張力には加えて「静けさの中の微細な震え」(アイソメトリックな緊張) の項を持つ:
  高域エネルギー × TREMOR_GAIN × (全体の揺れが小さいほど 1)。
  大きく激しく振れば振動のみ、止まったまま震えれば張力にも配分される
- 加速/減速: 平滑化した |a| 包絡線 (約150ms) の増減に変更。速い震えでは立たず、
  持続的な加減速 (慣性感) のみ拾う
- リズム: 自己相関ピークからノイズ床 (~0.5) を差し引いた有意分のみ
- 正規化: 走行 min/max のレンジ半減期を約5分に (インスタレーションの時間スケール)
- 重力要素: 自由落下に加え「重力への抗い」(重力と逆向きの持続加速) を追加、max で合成
- 処理: 取り込みはセンサーレートそのまま、特徴計算・出力は 50ms (20Hz)
- 正規化: 走行 min/max (減衰つき) を維持 — インスタレーション形式のため

## 単位の前提

- accel / gravity: G (×9.80665 で m/s²)
- gyro: rad/s (deg/s だった場合は elements.js の `GYRO_DEG = 1` に)
